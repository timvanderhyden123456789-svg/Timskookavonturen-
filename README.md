# Tims kook avonturen, self-contained versie

Deze versie is gemaakt voor GitHub Pages en bevat de gebruikte foto's direct in de code.
Daardoor zijn er geen losse afbeeldingsmappen nodig en is de kans kleiner dat blogafbeeldingen ontbreken na upload.

Upload deze bestanden uitgepakt naar de root van je GitHub repository:
- index.html
- blog.html
- over-tim.html
- email.html
- social.html
- styles.css
- script.js
- .nojekyll

Daarna in GitHub:
Settings > Pages > Deploy from a branch > main > /(root)
