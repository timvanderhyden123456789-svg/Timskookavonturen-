# Tims kook avonturen – GitHub Pages update Upload alle bestanden en mappen uit deze map naar de root van je GitHub repository. Belangrijk: - upload niet alleen de html-bestanden - upload ook `styles.css`, `script.js`, `.nojekyll` en de hele map `assets` Daarna: 1. Ga in GitHub naar Settings → Pages 2. Kies `Deploy from a branch` 3. Kies branch `main` 4. Kies folder `/ (root)` 5. Sla op Wacht daarna 1 à 3 minuten en refresh je site. In deze versie: - blogkaarten gebruiken echte foto's - homepage heeft een concreter doel en sterkere openingscopy - aparte pagina `over-tim.html` - stabiele navigatie zonder emoji-icons - speelsere updates/e-mailpagina
